## Mechanistic model and limits
This section supplements rather than repeats the reports' basic combat descriptions.

### Sprint, attacks and blocking
Let S_j be server sprint immediately before ordered packet/event j, I_j the predicate that the target's attackEntityFrom returns true, and K the held weapon's knockback enchantment contribution. Vanilla's extra impulse multiplier is i=K+1[S_j]. On an accepted attack with i>0, extra target velocity is 0.5i(-sin yaw, cos yaw), target vertical addition is 0.1, attacker horizontal motion is multiplied by 0.6, and attacker sprint is cleared. With i=0 that particular slowdown/reset branch is not entered. Server rejection does not execute it. Local prediction can disagree.

C0B start sets S=1, stop sets S=0; accepted attacks can clear S independently of a stop packet. The client's field named serverSprintState remembers what it last tried to announce; it is not an acknowledgement. Therefore a missing explicit STOP does not prove a failed reset, nor does a START prove the server was sprinting at a later attack. Server inference must include accepted attacks and other server changes.

“Zest tapping” is a community technique label, not a distinct vanilla mechanic or packet. Its operational definition must be the actual forward release/repress, sprint and attack sequence shown by the player. Test short versus longer release and spacing patterns under that definition; do not invent a special Zest reset threshold.

Block use affects at least four mechanisms: effective forward input, sprint eligibility, attack generation while using, and damage mitigation. Record C08 use intent/writes and C07 RELEASE_USE_ITEM separately from animation and actual item-use state. A sword-block animation pack cannot establish authoritative blocking. The server can accept or reject interactions differently.

Vanilla 1.8.9 has no 1.9 attack-strength recharge. That does not make every click damaging. Input suppression, client selection, server range validation, target immunity, game mode, plugins and cancellations all intervene. NS uses a broad squared entity-distance guard of 36 when visible and 9 otherwise; this is not a “6-block legitimate reach” recommendation, nor the client's ray criterion, nor an anti-cheat rule.

### Damage, trades and knockback
For an ordinary living target, let h be hurtResistantTime, H its maximum, L lastDamage, and a incoming damage before the later mitigation stages. Subject to early rejection checks:
- h>H/2 and a<=L: reject.
- h>H/2 and a>L: pass a−L into damageEntity, replace L, skip the fresh status/base-KB branch.
- h<=H/2: set h=H, pass a, set hurt animation, run fresh-hit path.

This is a stateful gate, not a universally fixed 500 ms click cooldown. H and tick duration can change; stronger hits, server plugins, zero final health loss and mitigation complicate labels. Each victim has its own gate, so reciprocal trades are not forbidden by a shared combat cooldown. Hit-selecting can change relative geometry, momentum and who enters the other's gate; taking a hit does not create a special offensive permission to hit through the opponent's immunity.

For base knockback (ordinary nonzero separation, resistance check passed), horizontal victim motion becomes
v_h^+=0.5 v_h^- +0.4 n_away;
v_y^+=min(0.5 v_y^-+0.4,0.4).
Add the extra attack impulse above when its branch executes. Direction from relative position and extra direction from attacker's yaw need not agree. A sprint jump adds about 0.2 along facing while replacing vertical jump velocity; its relation to an applied velocity packet is ordered, not commutative. A packet arriving before versus after the jump can produce different outcomes. This is a testable interaction, not proof that any “perfect” display minimizes KB.

Between impulses, a limited free-motion approximation is
v_{h,k+1}=f_k(v_{h,k}+a_k), p_{k+1}=p_k+v_k,
v_{y,k+1}=0.98(v_{y,k}−0.08),
with collision resolution, acceleration, jump and packet application in their actual code order. Vanilla's ordinary horizontal drag factor uses approximately 0.91 airborne and 0.91×ground slipperiness on ground; acceleration also depends on ground/slipperiness and input. These equations are not valid for water, ladders, collisions, flying, nonvanilla velocity handling, or as a substitute for the exact update order.

PikaNetwork and MMC backend KB constants, acceptance rules, proxy scheduling and server TPS are unverified. [PandaSpigot's configurable-knockback patch](https://github.com/hpfxd/PandaSpigot/blob/master/patches/server/0014-Configurable-knockback.patch), inspected here, demonstrates modifiable friction/impulse behavior in a real compatible fork; it does not identify either public server's implementation.

### What can be observed
| Quantity | Public-client status |
|---|---|
| Hook entry nanoTime, client tick index, binding and movement values at that hook | Measured at that stage, with hook/scheduling error |
| LWJGL event timestamp | Source timestamp with separately established clock origin/resolution; not a physical switch timestamp |
| C02/C0B logical send call | Measured intent; may be queued/cancelled/replaced |
| Netty outbound handler order | Measured traversal at that chosen pipeline point; not NIC transmission/remote acceptance |
| S12/status arrival and main-thread application | Separately measured; status does not identify attacker |
| Own local sprint versus last observed outbound sprint transition | Separate observations; neither acknowledges server state |
| Remote encoded coordinates, interpolation target and rendered pose | Three distinct client quantities; future authoritative position hidden |
| RTT from ordinary server/tab mechanisms | Sampled and possibly smoothed/application-delayed; not exact current path delay |
| One-way delays, precise server phase, opponent input/RTT, private KB/anti-cheat rules | Unidentified without additional assumptions/instrumentation |
| USB switch time, monitor photon time | Require external instrumentation; a Java timestamp cannot recover them |

Let c be client clock, s=c+theta the server clock, D_up one-way upload delay, and E scheduled server emission time. A received timestamp has form r=E−theta+D_down+client_queue. Replacing theta by theta+epsilon and D_down by D_down+epsilon preserves r. Ordinary arrivals alone cannot separate these values. Similarly an RTT observation constrains D_up+D_down+processing, not each term; dividing RTT by two adds an assumption. See [RFC 7679 §3.7](https://www.rfc-editor.org/rfc/rfc7679.html) on one-way timing/synchronization uncertainty.

An attack's processing time in client-clock coordinates is
T_i=c_i^write+D_i^up+Q_i^server.
A “round to next tick” map is only one queue model. Real handler tasks can run within the same server tick in order, and a modded task drain can differ. Tick identity and within-tick ordinal must both be logged. TCP preserves byte order on one connection; it does not preserve user action order across clients, avoid head-of-line stalls, or guarantee particular flush timing.

With symmetric paths as an explicitly hypothetical example, a display at 300 ms RTT may reflect approximately 150 ms of download age before local queue/render delay, while your next action still faces upload and processing. These are not measurements of your actual one-way paths. Opponent packet age adds further uncertainty. No confidence interval narrower than its unmodeled delay error becomes justified because the estimator uses nanosecond arithmetic.

Human feedback has another delay L_human+L_display+L_capture. If the remaining target interval ends sooner than that combined distribution, an immediate “tap now” cue cannot reliably affect the event it describes. Prefer post-exchange feedback and advance rhythm practice. Measure each player's cue-response distribution privately rather than assigning a universal 200 ms reaction constant.

A Kalman filter is a possible smoothing tool, not authority recovery: teleports, collisions, quantization and velocity packets create discontinuities. Reset/update modes on these events; compare an alpha-beta filter and constant-velocity baseline before more complex models. “Low residual error” on interpolated positions is not future server hitbox accuracy.

Novel hypotheses worth testing are (i) conditioning learning on execution completeness to avoid learning stall artifacts as network strategy; (ii) choosing by relative-delay robustness instead of exact tick phase; and (iii) censoring unattributed impulse transitions before SPAR. This search did not establish worldwide novelty or patent originality.

## Strongest candidate: observable execution first, selective personalized windows second (Deliverable E)
### Stage 0, implemented exact diagnostic
Event e=(t, sourceTime, session, producer, sequence, correlation, type, stage, tick, entity, flags, x,y,z). All t values supplied to the kernel must use one process's nanoTime domain; sourceTime is opaque separate metadata. Never subtract client/server clocks without a fit.

For an eligible queue-observed forward-up U_j and subsequent forward-down D_j in the same context, define
M_j={movement-consumption samples m with U_j <= m < D_j and forward_binding(m)=UP}.
Use actual MAIN producer sequence for interval membership; equal t values remain ordered. Define:
- sampled release iff M_j is nonempty;
- unsampled release iff M_j empty AND the interval and capture are complete;
- censored otherwise.

“Sampled” means a binding-up state was present at the movement-consumption observation, not that a sprint reset or advantageous hit occurred. MODIFIED_INPUT remains visible; a zero effective forward float alone is not evidence of W release. SYNTHETIC mutation/focus/connection/correction boundaries censor intervals. Incomplete captures suspend subsequent verdicts for the recording; this conservative implementation requires a new recording to recover.

State: rawKnown/rawDown; releaseOpen/releaseSampled/releaseAt; localSprintKnown/localSprint; writtenSprintKnown/writtenSprint; per-producer previousSequence/previousNs; session/context; counters. Ground-truth acceptance is separate and disabled by default. On end-of-recording, an unclosed release is censored once.

Pseudocode:
    on gap, backward producer time or known loss: invalidate; censor pending interval
    on context/session change: censor; unknown local/written sprint
    on eligible nonsynthetic queue up: open interval
    on movement SAMPLE with forward binding up: mark interval sampled
    on eligible queue down: close as sampled/unsampled
    on local sprint SAMPLE: update local observation
    on Netty sprint WRITE: update last written observation
    on ATTACK intent/write or HURT receive/apply: count distinct stages
    on ordinary feedback: never increment confirmed-own-hit
    on trusted private SERVER_ACCEPT: count explicit ground truth

No public probability of hit success is emitted. The current confidence interface is complete/incomplete plus known/unknown states, not an uncalibrated percentage. A release seen in the host queue but missed by movement is a deterministic local result under complete hooks. It remains conditional on hook coverage.

### Stage 1, fully specified research policy, not yet implemented or validated
Use a deliberately small contextual table rather than full PULSE:
- contexts: grounded/airborne × item-use/no-use × stable/variable local frame pacing; split server profile and session. Add movement direction or network categories only after an ablation supports them.
- candidate release durations: an experimental grid such as {15,30,45,60,80,100,140} ms. These are assigned practice conditions, not recommended public-server delays.
- hit-select candidates: offsets relative to a named observable incoming feedback/apply event, using a separately prespecified grid. Do not mix offsets from different anchors in one table.
- record assigned cue a, actual execution, quality/censoring, and server-labeled endpoint. For causal estimates keep intention-to-treat assigned arms; never remove difficult executions from one arm after randomization. The “clean execution” model is a separate descriptive diagnostic, not a substituted causal comparison.

For each independent randomized practice unit g, compute z_g,a = fraction of eligible attacks accepted with the server's sprint flag on at attack, with explicit eligibility fixed before treatment. Preserve damage/spacing safety endpoints separately. Units can be short sessions/blocks; attacks within a unit are correlated. Fit mean outcome mu_a(c), uncertainty by resampling paired units. For a simple isolated-trial Bernoulli sandbox only, Beta(1+s,1+n−s) is an optional smoothed descriptive estimate; it is not a valid independent-attack posterior for clustered human combat.

Choose the set A_safe(c) whose lower confidence bound for improvement over the tuned fixed baseline exceeds a prespecified practical margin eta, whose upper bound on spacing/damage harm is below its margin, and whose independent-unit count meets a preregistered minimum. Merge adjacent duration bins only when all included bins satisfy the rule. If empty, recommend baseline or abstain. Choose the shortest safe interval only if the lower-bound advantage is maintained; otherwise report the broad set without an optimum point.

Formally, for uncertain latent state/delay parameters u in an empirically calibrated set U_c and candidate cue a:
V(a,c)=inf_{u in U_c} E[Y(a)|c,u] − lambda C_spacing(a,c,u).
a*=argmax_{a in A_safe} V(a,c).
Y and lambda must be fixed before evaluation; for the initial trial use the single sprint-at-accepted-attack endpoint and spacing as a noninferiority guard, avoiding arbitrary composite-score weights. U must include correlated delay differences and frame/sampling uncertainty; it must not be fitted as a zero-width phase from RTT/2. If intervals widen until rankings overlap, abstain. If there is no validated latent model, use the randomized table directly and do not compute V.

Public observational play can update descriptive counts and flag distribution shift, not establish causal treatment benefit. A valid private policy is frozen before held-out testing; any online exploration/automated interventions remain in permitted private environments. Version every anchor, server profile, policy and feature schema.

### Technique-specific state
| Technique | Anchor and controllable variable | Required outcome distinction |
|---|---|---|
| W/Zest manual tapping | Observed attack generation plus forward release/repress; actual consumed samples | Unsampled input vs sampled state change vs C0B order vs server sprint at attack |
| Block-hit | Actual use begin/end and attack-generation branches | No attack generated vs generated/rejected; defensive mitigation vs sprint/spacing cost |
| Hit-select/midtrade | Named incoming receive/apply event and counterattack generation | Delayed cue vs actual server attack order; both victims' immunity; range and relative motion |
| Combo maintenance | Sequence of accepted exchanges and relative position/velocity | Excess KB/separation can reduce next-hit probability; maximizing KB is not equivalent to winning |

For a richer geometric model use relative state r=p_opponent−p_self, w=v_opponent−v_self. At uncertain horizon tau, r(t+tau)≈r+w*tau+0.5*a_rel*tau². Propagate a set or covariance only within one motion mode; collision/teleport/unknown input broadens it. Attack acceptance is an event through server code, not merely norm(r)<3.0. A favorable window is the set of cue times meeting both registration and spacing criteria with calibrated lower probability bounds. An empty window is a meaningful answer.

Failure conditions: incomplete hooks, multiple producers using one ring, unknown synthetic edits, reconnect/entity reuse, untrusted labels, changed server code, phase/delay nonidentifiability, too few randomized units, policy distribution shift, or overhead above the frame-time budget. Stop cueing rather than invent a narrower interval.

Integrate the passive execution analyzer first. Its most useful initial output is “your forward-up was never consumed” or “an attack was not generated while unblocking,” with an inspectable stage trace. Then test broad personalized windows against a genuinely tuned fixed strategy. At 180–300 ms, execution reliability, packet order and spacing are supportable training targets; exact hidden-server-tick cues are not yet supportable.

[Jump Reset Indicator source at 5d535ff](https://github.com/sootysplash/jump-reset/tree/5d535ff2d1ca9d18dbc5dc3e01ae6b09bf17e7f0) is a Fabric project linked from its [Modrinth listing](https://modrinth.com/project/kJEc5zbS); it is not a Java 8/Forge 1.8.9 drop-in. Additional code observations/inferences:

## Black-box experiments that can resolve unknowns
Use an authorized private server, fixed client build/version hash and a screen recording synchronized to the client/server trace. Do not redistribute proprietary binaries. Save settings screenshots and record every changed option.

1. Sweep jump execution at each offset around server-confirmed incoming hit; vary only the download delay. Does the displayed score move with packet receipt/application or with server time?
2. Hold upload fixed and vary download; repeat with the opposite asymmetry. A change with one direction alone can distinguish classes of anchors, not prove exact internal code.
3. Stall main thread after packet ingress but before application. Compare HUD labels against receive and apply ticks.
4. Tap jump briefly without actual jumping (airborne, low ceiling, or prevented jump). Distinguish key/binding hook from executed jump.
5. Send two controlled damage events with one jump, then two jumps around one damage. Observe pairing, expiration and whether labels are rewritten.
6. Produce a stronger-damage accepted event without a fresh vanilla status, and an attack animation rejected by server immunity. Test false negatives/positives.
7. Vary target/window settings by one tick, hold the trace fixed, and check exact boundary inclusion. Repeat at 10 versus 20 TPS with true tick durations recorded.
8. Reconnect, respawn, change world/focus, and test startup defaults. Do old ages/streaks contaminate new sessions?
9. Record 0–300 ms one-way changes and compare stable versus jittered paths. Adaptive behavior requires a repeatable rule change beyond configured fixed offsets; subjective usefulness is insufficient.

Competing predictions must be registered before seeing the traces. A few screenshots cannot distinguish tick-based input, tick-based packet feedback and a shifted fixed window if their timestamps coincide in that trial. The goal is to force those anchors apart.

A demonstrably better system would need lower ground-truth attribution error or better randomized manual-combat outcomes at matched overhead and cue coverage. This prototype offers testable execution diagnostics that the inspected open-source scorer lacks; it does not claim to have beaten Lunar.

SCHEMA AND BUFFER DESIGN
CSV schema version 1 columns:
ns,source_ns,session,producer,sequence,correlation,type,stage,tick,entity,flags,x,y,z

The Java source below defines the numeric enums. A reader must preserve per-producer order and stage, not impose fictitious cross-thread causality by sorting solely by timestamps. The worker's drain order is an observed file order, not proof that every MAIN event preceded every NETWORK event. Current analysis does not join arbitrary cross-thread packets to a particular attack.

Each SPSC ring stores five long arrays, five int arrays and three double arrays, approximately 84 bytes of primitive payload per slot plus headers/control fields. Two 4096-slot rings therefore have about 688,128 bytes of primitive payload, not a measured total heap footprint. Capacity is fixed, power of two, at most 65536. Overflow drops the newest event and preserves a sequence gap and loss footer. Thread ownership misuse is counted. The capture method performs no formatting, reflection, file I/O, explicit allocation or clock read; real adapters still incur timestamp and hook cost.

Worker: bounded batches of up to 128 events per ring, CSV formatting off capture threads, snapshot publication about 10 Hz, parks when idle. This is a design, not a performance benchmark. CSV disk output is not size-bounded in the current prototype; recording duration/rotation/storage limits remain an integration task. Buffer capacity does not bound total disk usage.

Replay refuses malformed schema/values, unknown identifiers, duplicate loss trailers, events after the loss trailer and data after END. Missing END or missing loss trailer marks incomplete. An unfinished release is censored at recording end. Default replay never confirms own hits from hurt/velocity. Trusted server trace mode requires explicit opt-in and a correctly prepared trace; a flag is not cryptographic authentication.

    }

    private static final class Gate { volatile boolean accepting = true; }

    /** SPSC ring. One owning producer and one owning consumer; ownership is checked. */
    public static final class Ring {
        private final int mask, producer;
        private final long[] ns, source, session, seq, correlation;
        private final int[] type, stage, tick, entity, flags;
        private final double[] x, y, z;
        private volatile long head, tail;
        private long nextSequence;
        private volatile long dropped;
        private final AtomicLong producerOwner = new AtomicLong();
        private final AtomicLong consumerOwner = new AtomicLong();
        private final AtomicLong misuse = new AtomicLong();
        private final Gate gate;
        private volatile boolean inOffer;

        public Ring(int capacity, int producer) { this(capacity, producer, new Gate()); }
        private Ring(int capacity, int producer, Gate gate) {
            if (capacity < 2 || capacity > 65536 || (capacity & (capacity - 1)) != 0)
                throw new IllegalArgumentException("capacity must be a power of two in [2,65536]");
            if (producer < MAIN || producer > SERVER) throw new IllegalArgumentException("producer");
            this.producer = producer; this.gate = gate; mask = capacity - 1;
            ns = new long[capacity]; source = new long[capacity];
            session = new long[capacity]; seq = new long[capacity]; correlation = new long[capacity];
            type = new int[capacity]; stage = new int[capacity]; tick = new int[capacity];
            entity = new int[capacity]; flags = new int[capacity];
            x = new double[capacity]; y = new double[capacity]; z = new double[capacity];
        }

        private boolean owns(AtomicLong owner) {
            long id = Thread.currentThread().getId(), current = owner.get();
            return current == id || (current == 0 && owner.compareAndSet(0, id));
        }

        /**
         * No allocations or clock reads here. Pass ns from the actual observation hook.
         * sourceNs is an optional timestamp in a separately documented clock domain.
         * Full buffers drop the new record; sequence gaps and a loss footer expose it.
         */
        public boolean offer(long atNs, long sourceNs, long sessionId, long token,
                             int eventType, int eventStage, int clientTick, int entityId,
                             int eventFlags, double a, double b, double c) {
            if (!gate.accepting) return false;
            if (!owns(producerOwner)) { misuse.incrementAndGet(); return false; }
            inOffer = true;
            try {
                if (!gate.accepting) return false;
                long sequence = ++nextSequence, h = head;
                if (h - tail >= ns.length) { dropped++; return false; }
                int i = (int) h & mask;
                ns[i] = atNs; source[i] = sourceNs; session[i] = sessionId;
                seq[i] = sequence; correlation[i] = token;
                type[i] = eventType; stage[i] = eventStage; tick[i] = clientTick;
                entity[i] = entityId; flags[i] = eventFlags;
                x[i] = a; y[i] = b; z[i] = c;
                head = h + 1; // volatile release publishes the complete record
                return true;
            } finally { inOffer = false; }
        }

        public boolean poll(Event out) {
            if (!owns(consumerOwner)) { misuse.incrementAndGet(); return false; }
            long t = tail;
            if (t == head) return false; // volatile acquire before payload reads
            int i = (int) t & mask;
            out.ns = ns[i]; out.sourceNs = source[i]; out.session = session[i];
            out.sequence = seq[i]; out.correlation = correlation[i]; out.producer = producer;
            out.type = type[i]; out.stage = stage[i]; out.tick = tick[i];
            out.entity = entity[i]; out.flags = flags[i];
            out.x = x[i]; out.y = y[i]; out.z = z[i];
            tail = t + 1;
            return true;
        }
        public long dropped() { return dropped; }
        public long misuse() { return misuse.get(); }
        public boolean isEmpty() { return head == tail; }
        private boolean quiescent() { return !inOffer; }
    }

    /** Descriptive local analyzer. It intentionally makes no public-server hit claims. */
    public static final class Analyzer {
        private final boolean trustServerTruth;
        private final long[] previousSequence = new long[3];
        private final long[] previousNs = new long[3];
        private final boolean[] hasPrevious = new boolean[3];
        private boolean context, releaseOpen, releaseSampled, rawKnown, rawDown;
        private boolean localSprintKnown, localSprint, writtenSprintKnown, writtenSprint;
        private boolean complete = true;
        private long session = Long.MIN_VALUE, releaseAt;
        private long unsampled, sampled, censored, modifiedSamples, attackIntents, attackWrites;
        private long hurtReceives, hurtApplies, velocityReceives, useWrites, confirmedHits, gaps;
        private long lastFrameNs, lastFrameInterval;
        private boolean hasFrame;
        private long latestObservationNs;
        public Analyzer() { this(false); }
        public Analyzer(boolean trustServerTruth) { this.trustServerTruth = trustServerTruth; }

        private void censor() {
            if (releaseOpen) censored++;
            releaseOpen = false; rawKnown = false;
        }

        /** Close a recording boundary without inventing a matching press. Idempotent. */
        public void finish() { censor(); }

        public void invalidate() {
            complete = false; censor(); writtenSprintKnown = false;
        }

        public void accept(Event e) {
            if (e.producer < 0 || e.producer > 2) { invalidate(); return; }
            int p = e.producer;
            if (hasPrevious[p] && (e.sequence != previousSequence[p] + 1
                    || e.ns - previousNs[p] < 0)) {
                gaps++; invalidate();
            } else if (!hasPrevious[p] && e.sequence != 1) {
                gaps++; invalidate();
            }
            previousSequence[p] = e.sequence; previousNs[p] = e.ns; hasPrevious[p] = true;
            latestObservationNs = e.ns;
            if (p == MAIN && e.type == CONTEXT) {
                boolean next = (e.flags & (FOCUSED | IN_WORLD | GAMEPLAY))
                        == (FOCUSED | IN_WORLD | GAMEPLAY);
                if (e.session != session || next != context) {
                    censor(); localSprintKnown = false; writtenSprintKnown = false;
                    hasFrame = false;
                }
                session = e.session; context = next;
                return;
            }
            if (e.session != session) return; // retain in log; don't join across connections
            if (p == MAIN) {
                if (e.type == FORWARD_EDGE && e.stage == INPUT_QUEUE && context && complete) {
                    if ((e.flags & SYNTHETIC) != 0) { censor(); return; }
                    boolean down = (e.flags & DOWN) != 0;
                    if (rawKnown && rawDown == down) return; // repeat, not a fresh edge
                    rawKnown = true; rawDown = down;
                    if (!down) {
                        releaseOpen = true; releaseSampled = false; releaseAt = e.ns;
                    } else if (releaseOpen) {
                        if (e.ns - releaseAt < 0) { invalidate(); return; }
                        if (releaseSampled) sampled++; else unsampled++;
                        releaseOpen = false;
                    }
                } else if (e.type == MOVEMENT_SAMPLE && e.stage == SAMPLE) {
                    if ((e.flags & MODIFIED_INPUT) != 0) modifiedSamples++;
                    if (releaseOpen && context && complete && (e.flags & BINDING_DOWN) == 0)
                        releaseSampled = true;
                    // moveForward == 0 is NOT evidence that W was released.
                } else if (e.type == BINDING_CHANGE && (e.flags & SYNTHETIC) != 0) {
                    censor();
                } else if (e.type == LOCAL_SPRINT && e.stage == SAMPLE) {
                    localSprintKnown = true; localSprint = (e.flags & DOWN) != 0;
                } else if (e.type == ATTACK && e.stage == INTENT) attackIntents++;
                else if (e.type == FRAME) {
                    if (hasFrame) lastFrameInterval = e.ns - lastFrameNs;
                    lastFrameNs = e.ns; hasFrame = true;
                } else if (e.type == CORRECTION) censor();
            }
            if (p == NETWORK && e.stage == WRITE) {
                if (e.type == SPRINT_START || e.type == SPRINT_STOP) {
                    writtenSprintKnown = true; writtenSprint = e.type == SPRINT_START;
                } else if (e.type == ATTACK) attackWrites++;
                else if (e.type == USE_START || e.type == USE_END) useWrites++;
            }
            if (e.type == HURT && e.stage == RECEIVE) hurtReceives++;
            if (e.type == HURT && e.stage == APPLY) hurtApplies++;
            if (e.type == VELOCITY && e.stage == RECEIVE) velocityReceives++;
            if (trustServerTruth && p == SERVER && e.type == SERVER_ACCEPT
                    && e.stage == GROUND_TRUTH) confirmedHits++;
        }

        public Snapshot snapshot() {
            return new Snapshot(complete, unsampled, sampled, censored, modifiedSamples,
                    attackIntents, attackWrites, hurtReceives, hurtApplies, velocityReceives,
                    useWrites, confirmedHits, gaps, localSprintKnown, localSprint,
                    writtenSprintKnown, writtenSprint, lastFrameInterval, latestObservationNs);
        }
    }

    /** Immutable, worker-published HUD state; construction/formatting stays off capture threads. */
    public static final class Snapshot {
        public final boolean complete, localSprintKnown, localSprint,
                writtenSprintKnown, writtenSprint;
        public final long unsampledReleases, sampledReleases, censoredReleases,
                modifiedSamples, attackIntents, attackWrites, hurtReceives, hurtApplies,
                velocityReceives, useWrites, confirmedHits, gaps, frameIntervalNs, observationNs;
        public final String hudText;
        private Snapshot(boolean complete, long unsampled, long sampled, long censored,
                         long modified, long intents, long writes, long hurtRx, long hurtApply,
                         long velocity, long uses, long confirmed, long gaps,
                         boolean localKnown, boolean local, boolean writtenKnown, boolean written,
                         long frame, long at) {
            this.complete = complete; unsampledReleases = unsampled; sampledReleases = sampled;
            censoredReleases = censored; modifiedSamples = modified;
            attackIntents = intents; attackWrites = writes;
            hurtReceives = hurtRx; hurtApplies = hurtApply; velocityReceives = velocity;
            useWrites = uses; confirmedHits = confirmed; this.gaps = gaps;
            localSprintKnown = localKnown; localSprint = local;
            writtenSprintKnown = writtenKnown; writtenSprint = written;
            frameIntervalNs = frame; observationNs = at;
            hudText = complete
                    ? "CombatIQ | unsampled " + unsampled + " | sampled " + sampled
                      + " | attack writes " + writes + " | server acceptance unknown"
                    : "CombatIQ | incomplete telemetry; timing verdicts suspended";
        }
    }

    public static void writeEvent(Writer out, Event e) throws IOException {
        out.write(e.ns + "," + e.sourceNs + "," + e.session + "," + e.producer + ","
                + e.sequence + "," + e.correlation + "," + e.type + "," + e.stage + ","
                + e.tick + "," + e.entity + "," + e.flags + ","
                + e.x + "," + e.y + "," + e.z + "\n");
    }

    /** Strict schema/version, explicit loss trailer, and conservative truncated-log handling. */
    public static Snapshot replay(Reader input, boolean trustServerTruth) throws IOException {
        BufferedReader reader = new BufferedReader(input);
        if (!"# CombatIQ schema=1".equals(reader.readLine())
                || !HEADER.equals(reader.readLine())) throw new IOException("Unsupported telemetry schema");
        Analyzer a = new Analyzer(trustServerTruth);
        Event e = new Event();
        String line; boolean ended = false, lossSeen = false;
        while ((line = reader.readLine()) != null) {
            if (line.length() > 2048) throw new IOException("Oversized telemetry row");
            if (line.startsWith("# LOSS,")) {
                if (lossSeen) throw new IOException("Repeated loss trailer");
                lossSeen = true;
                String[] f = line.split(",", -1);
                if (f.length != 5) throw new IOException("Malformed loss trailer");
                try {
                    for (int i = 1; i < 5; i++) {
                        long n = Long.parseLong(f[i]);
                        if (n < 0) throw new NumberFormatException("negative loss");
                        if (n != 0) a.invalidate();
                    }
                } catch (NumberFormatException ex) { throw new IOException("Malformed loss count", ex); }
                continue;
            }
            if ("# END".equals(line)) { ended = true; break; }
            if (lossSeen) throw new IOException("Event after loss trailer");
            if (line.startsWith("#")) throw new IOException("Unknown telemetry control row");
            String[] f = line.split(",", -1);
            if (f.length != 14) throw new IOException("Malformed telemetry row");
            try {
                e.ns = Long.parseLong(f[0]); e.sourceNs = Long.parseLong(f[1]);
                e.session = Long.parseLong(f[2]); e.producer = Integer.parseInt(f[3]);
                e.sequence = Long.parseLong(f[4]); e.correlation = Long.parseLong(f[5]);
                e.type = Integer.parseInt(f[6]); e.stage = Integer.parseInt(f[7]);
                e.tick = Integer.parseInt(f[8]); e.entity = Integer.parseInt(f[9]);
                e.flags = Integer.parseInt(f[10]); e.x = Double.parseDouble(f[11]);
                e.y = Double.parseDouble(f[12]); e.z = Double.parseDouble(f[13]);
                if (!Double.isFinite(e.x) || !Double.isFinite(e.y) || !Double.isFinite(e.z))
                    throw new NumberFormatException("non-finite payload");
                if (e.producer < MAIN || e.producer > SERVER || e.sequence <= 0
                        || e.type < CONTEXT || e.type > CORRECTION
                        || e.stage < INPUT_QUEUE || e.stage > GROUND_TRUTH
                        || e.flags < 0 || (e.flags & ~127) != 0)
                    throw new NumberFormatException("unknown event identifier");
            } catch (NumberFormatException ex) { throw new IOException("Invalid telemetry value", ex); }
            a.accept(e);
        }
        if (!ended || !lossSeen) a.invalidate();
        else if (reader.readLine() != null) throw new IOException("Data after END");
        a.finish();
        return a.snapshot();
    }

    /**
     * Optional async CSV recording. Hooks offer only primitives. One writer owns both
     * consumers and the Analyzer. Drain order is recorded, not asserted global causality.
     * Call stop() on the game thread; awaitStopped() only from a non-game shutdown/tool thread.
     */
    public static final class Session implements AutoCloseable {
        private final Gate gate = new Gate();
        public final Ring main, network;
        private final Thread worker;
        private volatile Snapshot snapshot = new Analyzer().snapshot();
        private volatile IOException failure;
        private volatile boolean stopped;
        public Session(final Path output, int capacity) {
            main = new Ring(capacity, MAIN, gate); network = new Ring(capacity, NETWORK, gate);
            worker = new Thread(new Runnable() {
                public void run() { record(output); }
            }, "VelvetG-CombatIQ-recorder");
            worker.setDaemon(true); worker.start();
        }
        public boolean isAccepting() { return gate.accepting; }
        public Snapshot snapshot() { return snapshot; }
        public IOException failure() { return failure; }
        public boolean isStopped() { return stopped; }
        public void stop() { gate.accepting = false; LockSupport.unpark(worker); }
        private void record(Path path) {
            Analyzer analyzer = new Analyzer(); Event event = new Event();
            long lastPublish = System.nanoTime();
            try (BufferedWriter out = Files.newBufferedWriter(path, StandardCharsets.UTF_8,
                    StandardOpenOption.CREATE_NEW, StandardOpenOption.WRITE)) {
                out.write("# CombatIQ schema=1\n"); out.write(HEADER); out.write('\n');
                while (gate.accepting || !main.quiescent() || !network.quiescent()
                        || !main.isEmpty() || !network.isEmpty()) {
                    int count = 0;
                    for (int i = 0; i < 128 && main.poll(event); i++) {
                        analyzer.accept(event); writeEvent(out, event); count++;
                    }
                    for (int i = 0; i < 128 && network.poll(event); i++) {
                        analyzer.accept(event); writeEvent(out, event); count++;
                    }
                    if (main.dropped() + network.dropped() + main.misuse() + network.misuse() > 0)
                        analyzer.invalidate();
                    long now = System.nanoTime();
                    if (now - lastPublish >= 100000000L) {
                        snapshot = analyzer.snapshot(); lastPublish = now;
                    }
                    if (count == 0) LockSupport.parkNanos(1000000L);
                }
                if (main.dropped() + network.dropped() + main.misuse() + network.misuse() > 0)
                    analyzer.invalidate();
                analyzer.finish();
                out.write("# LOSS," + main.dropped() + "," + network.dropped() + ","
                        + main.misuse() + "," + network.misuse() + "\n# END\n");
                snapshot = analyzer.snapshot();
            } catch (IOException ex) { failure = ex; gate.accepting = false; }
            catch (RuntimeException ex) {
                failure = new IOException("Recorder failed", ex); gate.accepting = false;
            } finally { stopped = true; }
        }
        public void awaitStopped(long timeoutMs) throws IOException, InterruptedException {
            if (timeoutMs <= 0) throw new IllegalArgumentException("positive timeout required");
            worker.join(timeoutMs);
            if (worker.isAlive()) throw new IOException("Recorder stop timed out");
            if (failure != null) throw failure;
        }
        public void close() { stop(); }
    }

    public static void main(String[] args) throws Exception {
        if (args.length < 1 || args.length > 2
                || (args.length == 2 && !"--trusted-server-trace".equals(args[1])))
            throw new IllegalArgumentException("Usage: CombatIQ recording.csv [--trusted-server-trace]");
        try (Reader in = Files.newBufferedReader(Paths.get(args[0]), StandardCharsets.UTF_8)) {
            Snapshot s = replay(in, args.length == 2);
            System.out.println(s.hudText);
            System.out.println("complete=" + s.complete + " censored=" + s.censoredReleases
                    + " hurtReceives=" + s.hurtReceives + " confirmedHits=" + s.confirmedHits);
        }
    }

#!/usr/bin/env python3
"""Compile/test the standalone kernel on JDK 8+; no game JAR or downloaded dependency."""
import argparse
import hashlib
import json
import os
import pathlib
import re
import shutil
import struct
import subprocess
import sys
import zipfile

ROOT = pathlib.Path(__file__).resolve().parent

def executable(name):
    suffix = ".exe" if os.name == "nt" else ""
    if os.environ.get("JAVA_HOME"):
        candidate = pathlib.Path(os.environ["JAVA_HOME"]) / "bin" / (name + suffix)
        if candidate.is_file():
            return str(candidate)
    found = shutil.which(name)
    if not found:
        raise SystemExit("Missing " + name + "; install a JDK (a JRE cannot compile).")
    return found

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--compile-only", action="store_true")
    args = parser.parse_args()
    build = ROOT / "build"
    classes = build / "classes"
    if classes.exists():
        shutil.rmtree(classes)
    classes.mkdir(parents=True)
    javac, java = executable("javac"), executable("java")
    version = subprocess.run([javac, "-version"], check=True, stdout=subprocess.PIPE,
                             stderr=subprocess.STDOUT, universal_newlines=True).stdout.strip()
    match = re.search(r"javac (?:1\.)?(\d+)", version)
    if not match:
        raise SystemExit("Unrecognized compiler version: " + version)
    major = int(match.group(1))
    target = ["-source", "8", "-target", "8"] if major == 8 else ["--release", "8"]
    sources = sorted((ROOT / "src" / "main" / "java").rglob("*.java"))
    tests = sorted((ROOT / "src" / "test" / "java").rglob("*.java"))
    subprocess.run([javac] + target + ["-encoding", "UTF-8", "-Xlint:all", "-d", str(classes)]
                   + [str(p) for p in sources + tests], check=True)
    for path in classes.rglob("*.class"):
        if struct.unpack(">H", path.read_bytes()[6:8])[0] != 52:
            raise SystemExit("Non-Java-8 bytecode: " + str(path))
    result = {"compiler": version, "class_major": 52, "game_integration_tested": False,
              "performance_measured": False, "tests_executed": False}
    if not args.compile_only:
        run = subprocess.run([java, "-Xverify:all", "-cp", str(classes),
                              "me.movi.combatiq.CombatIQTest"], check=True,
                             stdout=subprocess.PIPE, stderr=subprocess.STDOUT,
                             universal_newlines=True)
        print(run.stdout, end="")
        (build / "test-results.txt").write_text(run.stdout, encoding="utf-8")
        subprocess.run([sys.executable, str(ROOT / "experiments" / "protocol.py"),
                        "--self-test"], check=True)
        result["protocol_tests_executed"] = True
        result["tests_executed"] = True
        result["test_output"] = run.stdout
    artifact = build / "combatiq-kernel.jar"
    with zipfile.ZipFile(str(artifact), "w", zipfile.ZIP_DEFLATED) as jar:
        manifest = zipfile.ZipInfo("META-INF/MANIFEST.MF", (1980, 1, 1, 0, 0, 0))
        jar.writestr(manifest, "Manifest-Version: 1.0\nMain-Class: me.movi.combatiq.CombatIQ\n\n")
        for path in sorted(classes.rglob("*.class")):
            if path.name.startswith("CombatIQTest"):
                continue
            entry = zipfile.ZipInfo(path.relative_to(classes).as_posix(), (1980, 1, 1, 0, 0, 0))
            jar.writestr(entry, path.read_bytes())
    result["artifact_sha256"] = hashlib.sha256(artifact.read_bytes()).hexdigest()
    (build / "validation.json").write_text(json.dumps(result, indent=2) + "\n", encoding="utf-8")
    print("Artifact:", artifact)
    print("This is a telemetry kernel/replay tool, not an installable Minecraft mod.")

if __name__ == "__main__":
    main()

#!/usr/bin/env python3
"""Offline condition manifests and paired analysis; never alters networking or generates inputs."""
import argparse
import csv
import itertools
import json
import math
import random
import statistics
import sys
import unittest

def conditions():
    result = []
    for rtt, share, profile in itertools.product((40, 120, 180, 240, 300, 400),
                                                (0.2, 0.5, 0.8),
                                                ("stable", "mild", "variable")):
        up, down = rtt * share, rtt * (1 - share)
        std = (0, 0) if profile == "stable" else ((2, 2) if profile == "mild"
                                                   else (up / 4, down / 4))
        result.append(dict(condition="%d-u%d-%s" % (rtt, round(share * 100), profile),
                           nominal_added_rtt_ms=rtt, upload_share=share,
                           upload_delay_ms=round(up, 6), download_delay_ms=round(down, 6),
                           upload_std_ms=round(std[0], 6), download_std_ms=round(std[1], 6),
                           distribution="normal", emulator_loss_pct=0,
                           emulator_reorder=False,
                           note="Added delay, not measured RTT; measure achieved paths and TCP stalls."))
    return result

def paired(rows, condition):
    groups = {}
    for row in rows:
        if row["condition"] != condition:
            continue
        cluster, strategy = row["cluster"], row["strategy"]
        if not cluster or strategy not in ("baseline", "candidate"):
            raise ValueError("Require named clusters and baseline/candidate strategies")
        value = float(row["value"])
        if not math.isfinite(value):
            raise ValueError("Non-finite endpoint")
        group = groups.setdefault(cluster, {})
        if strategy in group:
            raise ValueError("Aggregate within the randomization unit first; duplicate cluster arm")
        group[strategy] = value
    if len(groups) < 2 or any(set(v) != {"baseline", "candidate"} for v in groups.values()):
        raise ValueError("Require at least two complete independent paired clusters")
    return [v["candidate"] - v["baseline"] for _, v in sorted(groups.items())]

def quantile(values, p):
    values = sorted(values)
    at = (len(values) - 1) * p
    lo = int(at)
    return values[lo] + (values[min(lo + 1, len(values) - 1)] - values[lo]) * (at - lo)

def analyze(deltas, seed=731, draws=10000):
    if len(deltas) < 2 or draws < 100:
        raise ValueError("Insufficient paired units or draws")
    rng = random.Random(seed)
    n = len(deltas)
    observed = statistics.mean(deltas)
    bootstrap = [statistics.mean(deltas[rng.randrange(n)] for _ in range(n))
                 for _ in range(draws)]
    if n <= 16:
        null = [sum(s * d for s, d in zip(signs, deltas)) / n
                for signs in itertools.product((-1, 1), repeat=n)]
        p = sum(abs(x) >= abs(observed) - 1e-12 for x in null) / len(null)
        method = "exact paired label swap"
    else:
        hits = sum(abs(sum(rng.choice((-1, 1)) * d for d in deltas) / n)
                   >= abs(observed) - 1e-12 for _ in range(draws))
        p = (hits + 1) / (draws + 1)
        method = "Monte Carlo paired label swap"
    return dict(paired_clusters=n, mean_candidate_minus_baseline=observed,
                bootstrap_percentile_95=[quantile(bootstrap, .025), quantile(bootstrap, .975)],
                two_sided_randomization_p=p, randomization_method=method, seed=seed,
                assumptions=["Independent paired randomization units; arm labels exchangeable under sharp null",
                             "Aggregate encounters within a unit before this analysis",
                             "One prespecified condition/endpoint; adjust multiplicity outside this tool"],
                warning="No causal interpretation for self-selected observational strategies; small-sample CIs unstable.")

class Tests(unittest.TestCase):
    def test_matrix(self):
        c = conditions()
        self.assertEqual(len(c), 54)
        self.assertEqual(len(set(x["condition"] for x in c)), 54)
        for x in c:
            self.assertAlmostEqual(x["upload_delay_ms"] + x["download_delay_ms"],
                                   x["nominal_added_rtt_ms"])
            self.assertGreaterEqual(x["upload_std_ms"], 0)
    def test_pairing(self):
        rows = [dict(condition="x", cluster=str(i), strategy=s, value=str(i + (s == "candidate")))
                for i in range(3) for s in ("baseline", "candidate")]
        self.assertEqual(paired(rows, "x"), [1, 1, 1])
        with self.assertRaises(ValueError):
            paired(rows + [rows[0]], "x")
        with self.assertRaises(ValueError):
            paired(rows[:-1], "x")
    def test_statistics(self):
        s = analyze([0, 0, 0], draws=100)
        self.assertEqual(s["two_sided_randomization_p"], 1)
        s = analyze([1, 1, 1, 1], draws=100)
        self.assertEqual(s["two_sided_randomization_p"], .125)
        self.assertEqual(s["bootstrap_percentile_95"], [1, 1])
        self.assertEqual(analyze([1, -2, 3], draws=100),
                         analyze([1, -2, 3], draws=100))
        self.assertEqual(quantile([0, 10], .25), 2.5)

def main():
    parser = argparse.ArgumentParser(description=__doc__)
    mode = parser.add_mutually_exclusive_group(required=True)
    mode.add_argument("--matrix", action="store_true")
    mode.add_argument("--analyze", metavar="PAIRED_CSV")
    mode.add_argument("--self-test", action="store_true")
    parser.add_argument("--condition")
    parser.add_argument("--seed", type=int, default=731)
    args = parser.parse_args()
    if args.self_test:
        result = unittest.TextTestRunner(verbosity=2).run(unittest.defaultTestLoader.loadTestsFromTestCase(Tests))
        sys.exit(0 if result.wasSuccessful() else 1)
    if args.matrix:
        print(json.dumps(dict(schema=1, conditions=conditions()), indent=2))
    else:
        if not args.condition:
            parser.error("--analyze requires --condition")
        with open(args.analyze, newline="", encoding="utf-8") as source:
            reader = csv.DictReader(source)
            if reader.fieldnames != ["condition", "cluster", "strategy", "value"]:
                raise ValueError("Expected CSV header condition,cluster,strategy,value")
            result = analyze(paired(reader, args.condition), args.seed)
        result["condition"] = args.condition
        print(json.dumps(result, indent=2))

if __name__ == "__main__":
    main()
